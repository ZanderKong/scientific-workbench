# 演示样例

运行 `pnpm demo` 会在 `demo/workspace` 创建一套独立的 PVA 水凝胶验收工作区。生成器只接受不存在的目标目录；若目录已经存在，它会停止并报告路径，不删除或覆盖已有内容。可通过 `WORKBENCH_DEMO_DIR=/绝对/新目录 pnpm demo` 指定其他位置。

样例包括：

- `PVA-01`：一次独立冻结和解冻操作。
- `PVA-03`：三次冻结和三次解冻，每次操作都有独立区块身份和来源位置。
- `PVA-EG`：含乙二醇和名称带空格的设备。
- `Draft-01`：错配括号、无效属性、未绑定对象和样品内普通 `[论点]` 文本。
- `Import-01`：独立创建、About 两个样品且包含 CSV 和说明文件的 Data。
- `Analysis-01`：组织三个样品和 Import-01，包含模拟曲线附件、上下文导出和一条固定证据的正式 Claim。

CSV、PNG、说明文件和全部数值均明确标为模拟内容，只用于软件流程验收，不代表论文或真实实验结果。生成后的 `exports/` 保存可供 AI 阅读的 `context.md` 和 `manifest.json`。
