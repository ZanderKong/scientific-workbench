# 科研工作台讨论资料

这是科研工作台的产品语义、设计规则、讨论决策、验收清单和首版实现入口。

## 阅读顺序

1. [当前设计规则](./DESIGN_RULES.md)：唯一的当前有效规则来源。
2. [讨论与决策记录](./DISCUSSIONS.md)：记录为什么这样定、哪些方案已经被替代、还要讨论什么。
3. [验收测试计划](./TEST_PLAN.md)：把规则变成可执行的验收项；尚未完成的人工验收继续保持未验证。
4. [交互原型](./index.html)：当前静态原型。原型行为不自动代表已经确认或已经实现的底层能力。

## 当前共识

- Sample 文档是操作记录的事实源；Data 可独立导入，Analysis 可直接编辑，关联关系保留来源追溯。
- 一个 Sample 对应一个 Document。一级父 bullet 建议记录一个完整操作，子 bullet 通过 `[对象]｜属性：值` 填写该 Sample 在这次操作中的实际属性和值。
- 文档正文及时保存，完成编辑/切页后整篇提取；有效部分提交，无效部分保留文字，重复解析更新原记录。待更新状态持久化，失败可重试。
- 同一操作中重复出现同名对象且同一属性值不同，给出“操作可能过于复合”的轻量提醒；不阻止保存，也不自动拆分。
- Sample 编辑器里的 `[论点]` 在任何层级都只作为文本保留，不生成正式 Claim。只有 Data 和 Analysis/View 页面里的 Claim Editor 能创建可引用的正式 Claim。
- Data 是科学数据单元，不等同于文件；AI 只能新增带 provenance 的派生 DataComponent，不能覆盖 raw。
- 对象使用稳定 ID。改名、合并、废弃和永久删除分别处理，历史正文不被强制重写。

- 首版个人使用，本机运行、浏览器访问，采用明确的数据目录；附件先本地保存，可选 S3 兼容存储。
- 对象用 `[名称]`，行首类型用 `[数据]` / `[论点]`；支持中文与全角方括号，补全自动闭合，名称允许空格。
- 全部对象共用属性字典。属性值为文本，多值以 · 并列展示，首版无内置 sum、单位换算或科学事实校验。
- 别名由用户或 AI 明确填写；菜单按名称和别名搜索、选中插入标准名，正文按标准名精确匹配或创建，不自动近义词合并。
- 属性严格使用竖线、名称、冒号、非空值；支持全半角符号，无效段保留文字。补全保护中文输入法，单位为灰色提示。
- Data 多入口同步；移除样品 Data 区块只移除引用，保留数据、文件和历史来源。

- 文件含隐藏元数据头与正文，编辑器只渲染正文；数据库是便于检索、跳转的轻量索引。
- 轻量历史只查看/复制正文快照；Data 提交检查版本，正式论点固定证据快照，不做通用历史回滚。
- 应用不内置 AI，各功能提供 API 和 MCP；分析导出涉及材料的实际正文，读取最新结构前先处理待更新文档。
- S3 日常仅上传超过大小阈值且本地保存满 X 天的附件，X 默认 15 天；关闭期间不运行，下次启动继续。大小默认 100 MB 仍是建议。
- 上传核对成功后可保留双份或远端索引。手动全量备份独立执行，包含远端附件实际内容，可输出本地或 S3 并独立恢复。

## 规则状态

规则正文使用以下状态：

- **已确认**：本轮讨论已经确定，后续实现和测试按此执行。
- **建议**：当前推荐行为，仍可在后续讨论中调整。
- **待讨论**：尚未形成实现约束。
- **已替代**：历史方案，保留记录但不再作为当前行为。

规则编号稳定后，讨论、测试和实现说明都引用编号，不依赖章节位置。
